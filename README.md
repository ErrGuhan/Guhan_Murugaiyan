# Guhan Murugaiyan — Portfolio

Personal developer portfolio showcasing AI engineering, agent architectures, full-stack development, and creative UI engineering.

## 🚀 Live Preview & Features
- **Cinematic Preloader**: Custom SVG ring and golden typography animation.
- **Interactive Custom Cursor**: Magnetic follower with interactive states.
- **Dark Elegance Aesthetic**: Gold luxury accents (`#D4AF37`, `#FFDF73`) and glassmorphic micro-interactions.
- **Projects & Experience**: Showcasing full-stack and AI architecture projects.

## 🛠️ Tech Stack
- HTML5 / CSS3 (Vanilla)
- Vanilla JavaScript
- Node.js (Local development server)
- Google Fonts & Font Awesome

## 💻 Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/ErrGuhan/Guhan_Murugaiyan.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Guhan_Murugaiyan
   ```
3. Run the local preview server:
   ```bash
   node server.js
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
